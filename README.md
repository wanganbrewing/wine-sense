# WINE SENSE

ワインソムリエ・ワインエキスパート学習者向けの、比較学習／テイスティング演習アプリです。

Version 1.1.0では主要11か国・30タイプを収録しています。

## 初版の設計根拠

- J.S.A. 2026年度呼称資格認定試験の公開情報
- WSET Level 3 Award in Winesの公開Specificationに記載された主要産地・主要品種
- WSETが公開するSystematic Approach to Tastingの分析順序（外観・香り・味わい・結論）

本アプリはJ.S.A.またはWSETの公式教材ではありません。J.S.A.の正式な第一次試験範囲は当該年度の日本ソムリエ協会教本です。公開情報だけでは教本全体を再現できないため、初版は主要品種・主要産地のテイスティング比較に重点を置いています。

## 機能

- 似た品種・産地を同時表示する比較学習
- グループからそのままランダム試験へ移動
- 外観・香り・味わいの順に候補を除外する試験
- CLASSIQUE（主要10・4択）／PREMIER（主要20・8択）／GRAND（全30・12択）／ALL
- 累計正解数によるアプリ内認定（10問／20問／30問）
- CLASSIQUE・PREMIER・GRANDごとの個別リセット
- 白・赤・発泡・甘口／酒精強化による出題設定
- 日本語／英語UIとブラウザー言語による初期表示
- スマートフォン向けレイアウト
